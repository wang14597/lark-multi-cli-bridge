| 2026-06-09 | feat | [codex-sandbox-bypass-default](2026-06-09-codex-sandbox-bypass-default.md) | Codex bots couldn't reach the network, `git push`, or run `lark-cli` while claude bots could — an adapter-default asymmetry: claude spawns with `bypassPermissions`, codex fell back to its OS sandbox (no network, workspace-only writes).
